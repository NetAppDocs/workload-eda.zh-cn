= 了解NetApp Workload Factory for EDA
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
Workload Factory for EDA 可帮助您跨多个文件系统优化 FSx for ONTAP 。您可以自动化存储参数、分析性能限制，从而优化性能并降低运营成本，并获得 EDA 项目的见解。

它旨在与您的基础设施即代码 (IaC) 框架集成。

Workload Factory for EDA 提供仪表板和存储自动化框架及实用程序，帮助您管理多个 FSx for ONTAP文件系统。

它提供以下服务：

* link:task-use-overview-dashboard.html["概览信息板"]：提供集中式集群视图，帮助您监控 FSx for ONTAP 集群运行状况、容量和吞吐量，确定放置新卷的位置，就扩展容量和吞吐量做出明智的决策，并接收自动的容量建议。
* link:task-configure-dashboard.html["项目仪表板"]：提供跨 FSx for ONTAP 文件系统的存储消耗集中视图，以帮助您规划、评估成本并收集跨项目的存储使用情况信息。
* link:task-monitor-latency.html["FSx 延迟分析"]：通过可配置的警告和关键事件阈值，主动监控卷读取和写入延迟性能。包括使用 ONTAP QoS 延迟中心指标的自动基本分析，以及针对需要更深入识别根本原因的复杂场景的可选 AI 代理分析。
* link:learn-eda-workloads.html["CI/CD"]：利用 FSx for ONTAP卷克隆功能，简化并缩短软件构建时间。
