= 在 Workload Factory 中激活 Overview 仪表板以进行 EDA
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
激活概述仪表板，开始收集适用于 ONTAP 文件系统的 FSx 的 CloudWatch 指标。通过控制面板，您可以在一个位置查看集群运行状况、容量和吞吐量。



[[before-you-begin]]
== 开始之前

在激活仪表板之前，请确保满足下列要求。



[[aws-credentials-with-view-permissions]]
=== 具有查看权限的 AWS 凭据

您必须至少使用常规存储的读取（查看）权限在 Workload Factory 中配置 AWS 凭据。不支持 _Basic_ 凭据，因为它们不包括 CloudWatch 指标的必要读取权限。

如果您尚未配置具有查看权限的凭据，则在打开"概述"选项卡时将重定向到 AWS 凭据设置页面。

如果您尚未配置 AWS 凭据，请参见 link:https://docs.netapp.com/us-en/workload-setup-admin/add-credentials.html["添加 AWS 凭据"^]。



[[activate-the-dashboard]]
== 激活信息板

Workload Factory 使用查看权限验证凭据后，激活仪表板以开始收集适用于 ONTAP 文件系统的 FSx 的 CloudWatch 指标。


NOTE: 同意后，收集指标可能需要一些时间。正在进行首次收集时，仪表板将通知您。

.步骤
. 使用以下任一方式登录 link:https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html["主机体验"^]。
. 选择菜单 image:workloads-menu-icon.png["汉堡菜单图标"]，然后选择 *EDA*。
. 选择 *Overview* 选项卡。
. 如果未检测到具有查看权限的凭据，请选择 *Add credentials* 并按照提示使用查看权限配置 AWS 凭据。然后返回 *Overview* 选项卡。
. 查看同意提示，说明将为您的 FSx for ONTAP 文件系统收集的 CloudWatch 指标。
. 选择 *Activate* 以激活仪表板并开始收集指标。


.结果
Workload Factory 开始收集链接到您的 AWS 凭据的所有 FSx for ONTAP 文件系统的 CloudWatch 指标。当指标可用时，控制面板会自动填充。数据收集仍在进行时，系统会显示通知。
