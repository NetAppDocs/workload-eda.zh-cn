= 使用项目仪表板
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
作为负责监督 EDA 工作负载的 IT 管理员或项目经理，您可以使用"项目"选项卡观察和分析 FSx for ONTAP 文件系统和卷的项目使用情况。该仪表板可帮助您规划容量、评估成本并做出有关资源分配的数据驱动决策。您可以根据您的 AWS 标签创建最多五个自定义过滤器，并可选择单个或多个选项，以便根据您的特定业务需求（如项目、团队或应用程序）组织和过滤数据。

仪表板提供存储使用模式的可见性，帮助您识别资源密集型项目，跟踪成本，并在容量或性能问题影响您的 EDA 模拟之前优化存储分配。

此信息板可帮助您监控已分配容量、已使用容量、吞吐量和 IOPS 的存储使用情况。有关主动延迟性能监控，请参阅link:task-monitor-latency.html["监控卷延迟"]。

收集的 CloudWatch 指标包括：

* 已配置容量：表示已配置存储容量的卷级指标。
* 已用容量：表示已用存储空间的卷级指标。
* 平均/最大吞吐量：计算方法为指定时间段内 DataReadBytes 和 DataWriteBytes 之和的平均值或最大值。
* 平均/最大 IOPS：计算方法为：在指定时间段内，数据读取操作、数据写入操作和元数据操作的总和的平均值或最大值。




== 设置仪表板

通过设置自定义筛选器，您可以查看按业务结构（如按项目、团队或应用程序）组织的指标。这种组织方式可帮助您准确跟踪成本，确定哪些项目消耗最多资源，并就资源分配和预算规划做出明智的决策。

为了有效地使用仪表板，请根据您的业务需求在 FSx for ONTAP 卷上配置最多五个 AWS 标签，例如代表项目或业务单元的标签。有关详细信息，请参见<<配置自定义过滤器>>。

AWS 标记是 AWS 资源的元数据。它们可以帮助您以不同的方式对 AWS 资源进行分类，例如按项目、应用程序或业务部门进行分类。有关标记的详细信息，请参阅 https://docs.aws.amazon.com/whitepapers/latest/tagging-best-practices/what-are-tags.html["什么是标签？"^]和 https://docs.aws.amazon.com/resourcegroupstagging/latest/APIReference/overview.html["AWS 资源组标记 API 参考"^]。

配置完成后，在“标签配置”页面中提供 AWS 标签密钥名称和要在控制面板中显示的相应标签。

应用这些标签后，Workload Factory 开始收集和显示相关的 CloudWatch 指标。

您的仪表盘将成为一个动态工具，可以根据您的组织需求来组织、跟踪成本和筛选资源。



=== 配置自定义过滤器


NOTE: 只有第一个访问项目仪表板的管理员用户才能配置、添加或删除自定义筛选器。所有其他用户，包括后续管理员，都具有对筛选器的只读访问权限。

自定义筛选器允许您根据组织的运作方式组织仪表板数据。通过将筛选器与您的项目结构、团队或成本中心保持一致，您可以快速访问所需的特定数据，而无需浏览不相关的信息。这使得容量规划、成本跟踪和性能监控更加高效。

您可以根据 AWS 标签配置最多五个自定义过滤器。每个自定义过滤器需要三个组件：过滤器标签名称、AWS 标签键名称和选择类型（单选或多选）。如果您没有配置任何自定义过滤器，则默认过滤器（文件系统、卷类型和时间范围）仍然可用，因此您仍然可以查看仪表板并与之交互。

. 使用以下任一方式登录 link:https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html["主机体验"^]。
. 选择菜单 image:workloads-menu-icon.png["汉堡菜单图标用于导航至存储、EDA、AI、数据库、VMware 和管理等工作负载。"] 然后选择 *EDA*。
. 选择 *Project*。
+
如果您尚未配置仪表板，系统会自动提示您进行配置。

. 选择 *+ Add filters*。
. 对于要创建的每个自定义筛选器（最多五个），请提供以下内容：
+
** *Filter label name*：显示在控制面板中的显示名称。
** *AWS 标记密钥名称*：与此过滤器对应的 AWS 资源标记密钥。
** *多选*：选择此筛选器允许单选还是多选。选择 *多选* 时，您可以为此筛选器同时选择多个值。单选限制一次只能选择一个值。
+

NOTE: 筛选器按您配置的顺序显示在控制面板上。请考虑首先整理最常用的筛选器，以便更轻松地访问。



. 选择*应用*。
+
您可以通过选择自定义过滤器旁边的垃圾桶图标来删除该过滤器，然后再应用更改。

. 应用任何标签或筛选器后，要查看更改，请选择仪表板上的刷新图标。配置了新筛选器的动态仪表板将显示在您的 EDA 项目仪表板中。
. 要稍后编辑仪表板配置，请选择“配置”。




=== 筛选仪表板

筛选可帮助您专注于存储资源的特定子集，从而更轻松地分析趋势、识别问题并为利益相关者生成报告。通过组合多个过滤器，您可以回答特定的业务问题，例如"我的 ASIC 项目团队使用了多少存储空间？"或"美国西部地区哪些卷的 IOPS 最高？"

您可以使用默认筛选器和您创建的任何自定义筛选器的组合来筛选控制面板上显示的信息。

以下默认筛选器始终可用：

* 凭据
* 地区
* 文件系统
* 卷类型
* 时间范围


除了这些默认筛选器外，您配置的自定义筛选器还会显示在控制面板上。使用筛选器时：

* *多选筛选器*允许您同时选择多个值来拓宽您的视野。例如，您可以选择多个项目来查看合并指标。
* *单选筛选器*限制您一次只能选择一个值，在需要关注特定资源或类别时非常有用。


选择所需的筛选条件后，点击刷新图标即可更新仪表盘信息。

要了解卡片上显示的信息的说明，请选择该卡片的信息图标。



== 查看卷详细信息

了解汇总和单个卷的性能有助于您就容量规划和性能优化做出明智的决策。"总计"视图显示总体趋势，而"卷"视图可帮助您识别可能需要注意、优化或其他资源的特定卷。

控制面板提供两种查看模式来帮助您分析存储指标：总视图和卷视图。您可以使用控制面板上的可用选项卡在这些模式之间切换。



=== 总视图

Total 视图（默认）显示与所选筛选器匹配的所有卷的汇总指标。此视图提供整体存储性能的高级概览，显示综合容量、IOPS 和吞吐量指标。使用此视图了解总体趋势，规划未来容量需求，并报告跨项目或团队的总资源消耗。



=== 卷视图

Volume 视图显示各个卷随时间的性能表现，显示每个指标的前 10 个卷。此视图可帮助您识别推动资源使用的特定卷，并观察其在所选时间段内的行为。使用此视图可查找性能瓶颈，确定可能需要调整大小的卷，或确定哪些特定项目或工作负载消耗最多资源。

要切换到 Volume 视图，请选择仪表板上的 *Volume* 选项卡。



==== 显示的卷指标

当您选择卷视图时，仪表板将显示卷总数中的前 10 个卷。* *卷已用容量*：显示当前已用容量最高的卷。* *IOPS*：显示所选时间段内平均 IOPS 最高的卷。* *吞吐量*：显示所选时间段内平均吞吐量最高的卷。


NOTE: 控制面板仅显示每个指标的前 10 个卷。如果您有超过 10 个卷，某些卷可能不会显示在详细视图中。

当相同的卷出现在*卷使用容量*、*IOPS* 和*吞吐量*指标中时，仪表板在图例中使用一致的颜色编码，以便更轻松地跟踪不同指标中的特定卷。

水平轴显示时间范围，而图例显示图形中表示的所有卷（最多 10 个）。



==== 交互式卷数据

交互式悬停数据提供特定时间点的精确指标，帮助您将性能变化与特定事件或时间范围相关联。此详细信息对于排除性能问题、验证优化工作或向利益相关者解释资源使用模式很有价值。

您可以将鼠标悬停在图形中的任何卷线上以查看详细信息：

*卷使用容量*：显示卷名称、当时使用的容量和分配的容量。

*IOPS*：显示卷名称、时间范围内的平均 IOPS 以及时间范围内的最大 IOPS。

*吞吐量*：显示卷名、时间范围内的平均吞吐量以及时间范围内的最大吞吐量。

这些交互式数据可帮助您分析卷性能模式，并确定潜在的瓶颈或优化机会。
