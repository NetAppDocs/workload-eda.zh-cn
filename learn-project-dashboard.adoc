= 了解 Workload Factory for EDA 中的项目仪表板
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
Projects 仪表板可帮助 IT 管理员和项目经理观察和分析 FSx for ONTAP 文件系统和卷的项目使用情况。它提供了存储使用模式的可见性，帮助您识别资源密集型项目，跟踪成本，并在容量或性能问题影响您的 EDA 模拟之前优化存储分配。



== 项目仪表板的工作方式

Projects 控制面板收集与您的 AWS 凭据关联的所有 FSx for ONTAP 卷的 CloudWatch 指标。您可以根据 AWS 标签创建最多五个自定义筛选器，以根据您的特定业务需求（如项目、团队或应用程序）组织和筛选数据。

控制面板可帮助您：

* 规划容量并评估成本
* 做出关于资源分配的数据驱动决策
* 确定资源密集型项目
* 跨项目或团队准确跟踪成本
* 在发生问题之前优化存储分配


有关主动延迟性能监控，请参阅link:learn-latency-monitoring.html["了解延迟监控"]。



=== 收集的 CloudWatch 指标

仪表板将收集并显示以下 CloudWatch 指标：

* *已调配容量*：表示已调配存储容量的卷级指标。
* *已使用容量*：表示已使用存储的卷级指标。
* *平均/最大吞吐量*：计算为指定时间段内 DataReadBytes 和 DataWriteBytes 之和的平均值或最大值。
* *平均/最大 IOPS*：计算为指定时间段内 DataReadOperations、DataWriteOperations 和 MetadataOperations 总和的平均值或最大值。




== 自定义筛选器

自定义筛选器允许您根据组织的运作方式组织仪表板数据。通过将筛选器与您的项目结构、团队或成本中心保持一致，您可以快速访问所需的特定数据，而无需浏览不相关的信息。这使得容量规划、成本跟踪和性能监控更加高效。

您最多可以根据 AWS 标签配置五个自定义过滤器。每个自定义过滤器都需要以下组件：

* *筛选器标签名称*：显示在仪表板中的显示名称
* *AWS 标记密钥名称*：资源上使用的实际 AWS 标记密钥
* *选择类型*：单选或多选


如果您没有配置任何自定义过滤器，则默认过滤器（文件系统、卷类型和时间范围）仍然可用，因此您仍然可以查看仪表板并与之交互。



=== AWS 标记

AWS 标记是 AWS 资源的元数据。它们可以帮助您以不同的方式对 AWS 资源进行分类，例如按项目、应用程序或业务部门进行分类。

要有效使用自定义筛选器，请根据您的业务需求在 FSx for ONTAP 卷上配置 AWS 标记，例如，表示项目、团队或业务单元的标记。

有关标记的详细信息，请参阅 https://docs.aws.amazon.com/whitepapers/latest/tagging-best-practices/what-are-tags.html["什么是标签？"^]和 https://docs.aws.amazon.com/resourcegroupstagging/latest/APIReference/overview.html["AWS 资源组标记 API 参考"^]。



== 卷详细信息

控制面板提供查看模式，可帮助您分析不同详细信息级别的存储指标。



=== 总视图

Total 视图（默认）显示与所选筛选器匹配的所有卷的汇总指标。此视图提供整体存储性能的高级概览，显示综合容量、IOPS 和吞吐量指标。

使用此视图可以：

* 了解整体趋势
* 规划未来容量需求
* 报告跨项目或跨团队的总资源消耗




=== 卷视图

Volume 视图显示各个卷随时间的性能表现，显示每个指标的前 10 个卷。此视图可帮助您识别推动资源使用的特定卷，并观察其在所选时间段内的行为。

使用此视图可以：

* 查找性能瓶颈
* 识别可能需要调整大小的卷
* 确定哪些特定项目或工作负载消耗的资源最多




==== 显示的卷指标

当您查看单个卷时，控制面板将显示每个指标的卷总数中的前 10 个卷：

* *卷已用容量*：显示当前已用容量最高的卷。
* *IOPS*：显示选定时间段内平均 IOPS 最高的卷。
* *吞吐量*：显示选定时间段内平均吞吐量最高的卷。



NOTE: 控制面板仅显示每个指标的前 10 个卷。如果您有超过 10 个卷，某些卷可能不会显示在详细视图中。

当相同的卷在多个指标中出现时，控制面板在图例中使用一致的颜色编码，以便更轻松地跟踪不同指标中的特定卷。



==== 交互式卷数据

交互式悬停数据提供特定时间点的精确指标，帮助您将性能变化与特定事件或时间范围相关联。此详细信息对于排除性能问题、验证优化工作或向利益相关者解释资源使用模式很有价值。

将鼠标悬停在图形中的任何卷线上时，您可以查看：

* *卷已用容量*：卷名称、该时间点的已用容量和已分配容量
* *IOPS*：卷名称、时间范围内的平均 IOPS 和时间范围内的最大 IOPS
* *吞吐量*：卷名称、时间范围内的平均吞吐量和时间范围内的最大吞吐量
