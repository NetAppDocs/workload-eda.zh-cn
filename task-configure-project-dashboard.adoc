= 在 Workload Factory 中为 EDA 配置项目仪表板
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
为项目仪表板配置自定义筛选器，以根据您的业务结构（如项目、团队或成本中心）组织指标。这有助于您准确跟踪成本，识别哪些资源消耗最多容量，并就资源分配和预算规划做出明智的决策。通过将筛选器与您的组织运作方式保持一致，您可以快速访问相关数据，并提高容量规划、成本跟踪和性能监控的效率。



== 开始之前

要有效使用自定义筛选器，请根据您的业务需求在 FSx for ONTAP 卷上配置 AWS 标记，例如，表示项目、团队或业务单元的标记。



== 配置自定义过滤器


NOTE: 只有第一个访问 Projects 仪表板的管理员用户才能配置、添加或删除自定义筛选器。所有其他用户，包括后续管理员，都具有对筛选器的只读访问权限。

.关于此任务
您可以根据 AWS 标签配置最多五个自定义过滤器。每个自定义过滤器需要三个组件：过滤器标签名称、AWS 标签键名称和选择类型（单选或多选）。

如果您没有配置任何自定义过滤器，则默认过滤器（文件系统、卷类型和时间范围）仍然可用，因此您仍然可以查看仪表板并与之交互。

.步骤
. 使用以下任一方式登录 link:https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html["主机体验"^]。
. 选择菜单 image:workloads-menu-icon.png["汉堡菜单图标用于导航至存储、EDA、AI、数据库、VMware 和管理等工作负载。"] 然后选择 *EDA*。
. 选择 *Projects*。
+
如果您尚未配置仪表板，系统会自动提示您进行配置。

. 选择 *+ Add filters*。
. 对于要创建的每个自定义筛选器，请添加详细信息：
+
** 筛选器标签名称（仪表板中的显示名称）
** AWS 标记密钥名称（资源上使用的实际标记密钥）
** 选择类型（单选或多选）
+

NOTE: 筛选器按您配置的顺序显示在控制面板上。请考虑首先整理最常用的筛选器，以便更轻松地访问。



. 选择*应用*。
+
您可以通过选择自定义过滤器旁边的垃圾桶图标来删除该过滤器，然后再应用更改。

. 要在应用任何标签或筛选器后查看更改，请选择仪表板上的刷新图标。
. 要稍后编辑仪表板配置，请选择“配置”。


.结果
应用这些标签后，Workload Factory 将开始收集和显示相关 CloudWatch 指标。您的仪表板成为一个动态工具，用于根据您的组织需求组织、跟踪成本和筛选资源。
