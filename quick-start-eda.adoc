= Workload Factory for EDA 快速入门
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
通过设置环境、启用监控仪表板和配置延迟分析来优化 FSx for ONTAP 性能以支持 EDA 工作负载，从而开始使用 Workload Factory for EDA。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["一个"] 登录 Workload Factory
[role="quick-margin-para"]
你需要 https://docs.netapp.com/us-en/workload-setup-admin/sign-up-saas.html["在 Workload Factory 上注册一个帐户"^] 并使用以下任一方式登录： https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html["主机体验"^]。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["两个"]添加凭据和权限
[role="quick-margin-para"]
选择符合您需求的权限策略。

[role="quick-margin-para"]
如果您选择不授予权限，您可以开始使用 Workload Factory for EDA 来复制部分完成的代码示例。

[role="quick-margin-para"]
如果您选择授予权限，则需要手动向帐户添加凭据，包括选择工作负载功能（例如 EDA 和 AI），并为所需的权限创建 IAM 策略。

[role="quick-margin-para"]
https://docs.netapp.com/us-en/workload-setup-admin/add-credentials.html["了解如何添加凭据和权限"^]。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["三"] 设置环境以满足EDA要求
[role="quick-margin-para"]
您需要一个已部署并已发现的 FSx for ONTAP文件系统，其中至少包含一个已配置为 NFS 共享的卷。

[role="quick-margin-para"]
link:requirements-eda.html["了解更多关于EDA要求的信息"^]。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["四个"] 启用概览仪表板
[role="quick-margin-para"]
启用概述仪表板以监控 FSx for ONTAP 集群的运行状况、容量和吞吐量。接受同意提示，允许 Workload Factory 开始收集 CloudWatch 指标。

[role="quick-margin-para"]
link:task-activate-overview-dashboard.html["了解如何激活 Overview 控制面板"^]。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-5.png["五"] 配置 Projects 仪表板
[role="quick-margin-para"]
配置项目仪表板以监控系统运行状况、性能和存储使用情况，使您能够有效优化 EDA 环境。

[role="quick-margin-para"]
link:task-configure-project-dashboard.html["了解如何配置 Projects 仪表板"^]。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-6.png["六"] 为 ONTAP 延迟分析配置 FSx
[role="quick-margin-para"]
设置延迟阈值，以在影响模拟运行时间之前主动识别和解决性能问题。配置警告和关键警报，设置电子邮件或 SNS 通知以接收实时警报，利用自动化基本分析，并可选择通过配置 Amazon Bedrock 模型 ARN 为复杂场景启用 AI 分析。

[role="quick-margin-para"]
link:task-configure-latency-monitoring.html["了解如何配置延迟监控"^]。检测到事件后，您可以link:task-analyze-latency-trends.html["分析延迟趋势"^]使用交互式图形。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-7.png["七"] 与其他服务集成
[role="quick-margin-para"]
使用 Workload Factory REST API 将 EDA 与其他服务（如服务门户或 Perforce Helix Core）集成。

[role="quick-margin-para"]
link:integrate-perforce.html["了解如何将 EDA 与 Perforce 集成"^]。
